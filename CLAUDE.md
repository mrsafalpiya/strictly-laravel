## Agent skills

### Issue tracker

GitHub Issues on `mrsafalpiya/strictly-laravel`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Developing the Overlay

Any change to the Overlay, Kit Conversion or the Testbed App starts from a Problem in the register, `docs/problems.md`. Follow `docs/agents/developing-the-overlay.md`.
